PAYLINK SA HACKATHON PROTOTYPE

Files:
- index.html: application markup
- style.css: responsive styling
- app.js: client-side demo interactions
- assets/paylink-logo.jpg: supplied emblem image
- assets/paylink-icon.png: square icon made from the supplied emblem

Run locally by opening index.html in a modern browser. Google Fonts require internet access; system font fallbacks are included.
Important: this is a front-end prototype. QR art is illustrative, payment transactions are simulated, and no real money or Open Payments API is connected.
